# Batch-Selling-Price Conversion

Attach a price list (.xlsx), type a date, download the CSV for Batch Selling Price Change.
The Excel file is read in the browser; it is not uploaded or stored.

## Run on your computer
1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in the username, password and secret.
3. `npm run dev`, then open http://localhost:3000

Do not commit real price lists or `.env.local` (they are git-ignored).
